# Hangman Game

## Project Overview

The Hangman Game is a console-based Python application developed as part of the CodeAlpha Python Programming Internship. The player guesses a hidden word one letter at a time within a limited number of incorrect attempts.

---

## Features

- Random word selection
- Five predefined words
- Maximum of six incorrect guesses
- Input validation
- Duplicate letter checking
- Win/Lose messages
- Simple console interface
